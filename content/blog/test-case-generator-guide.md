## What to bring to the Test Case Generator

Bring the real source: the code, the job post, the diff, or the file.

Test Case Generator sends the input to a server so the work can run. Do not include passwords or account numbers. The free plan has a daily limit.

## A worked pass with the Test Case Generator

Paste a function and get a thorough test suite for Jest, PyTest or JUnit covering edge cases. The draft follows the text you supplied. A short label is a weak brief.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

Check names, numbers, and any line you would ship. Change one instruction and see whether the draft follows it.
