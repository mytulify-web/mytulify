[HTML to Markdown Converter](/converters-generators/html-to-markdown) is the tool for one job: convert HTML markup into clean Markdown. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the HTML to Markdown Converter

Paste a real snippet, not a description of the snippet, unless the tool asks you to describe one.

HTML to Markdown Converter runs in your browser. The file or the figures stay on your device.

## A worked pass with the HTML to Markdown Converter

Convert HTML markup into clean Markdown. Feed it a small valid sample and a sample you know is broken. The valid one should succeed and the broken one should point at the problem.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

Diff the output against the input for a formatter. For a generator, run the result in the real tool that will consume it.

## Where the HTML to Markdown Converter stops

HTML to Markdown Converter does not see your repository, your server, or the version of the library on your machine.

If your decision depends on a rule this page does not mention, a lender, a clinic, a teacher, a client, or the vendor of the file, use their rule. Keep this result as the draft you compare against that rule.
