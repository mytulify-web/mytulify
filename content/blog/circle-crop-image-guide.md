[Circle Crop Image](/image-tools/circle-crop-image) is the tool for one job: crop an image into a transparent circle. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the Circle Crop Image

Use the original image. Crop an image into a transparent circle.

Circle Crop Image runs in your browser. The file or the figures stay on your device.

## A worked pass with the Circle Crop Image

The download is a circle with transparent corners if the format allows transparency. JPG cannot store those corners. Use PNG if the circle must sit on another background.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

Compare the download with the original at 100% zoom on the part you care about: a face, a line of text, or the edge of the crop.

## Where the Circle Crop Image stops

Circle Crop Image changes the copy you download. It does not edit the file still sitting in your folder until you replace it.

If your decision depends on a rule this page does not mention, a lender, a clinic, a teacher, a client, or the vendor of the file, use their rule. Keep this result as the draft you compare against that rule.

## Questions

### What does the Circle Crop Image do?

It is there to crop an image into a transparent circle. The form on the [Circle Crop Image](/image-tools/circle-crop-image) page is the place you do that.

### How do I know the Circle Crop Image result is usable?

Compare the download with the original at 100% zoom on the part you care about: a face, a line of text, or the edge of the crop.

### What should I not trust the Circle Crop Image to decide?

Circle Crop Image changes the copy you download. It does not edit the file still sitting in your folder until you replace it.
