## What to bring to the CSRF Token Generator

Type the value in the form. Do not use a real password as a test on any tool that sends data to a server.

CSRF Token Generator runs in your browser. The file or the figures stay on your device.

## A worked pass with the CSRF Token Generator

Generate random anti-CSRF tokens for forms. Treat the output as a secret if it is a password, a key, or a token. Copy it to a manager and clear the box.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

For a hash, change one character of the input. The digest should change completely. For a generator, generate twice and expect two different outputs.
