[Image Color Picker](/image-tools/image-color-picker) is the tool for one job: pick HEX/RGB colors from any pixel of an image. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the Image Color Picker

Use the original image. Pick HEX/RGB colors from any pixel of an image.

Image Color Picker runs in your browser. The file or the figures stay on your device.

## A worked pass with the Image Color Picker

The HEX and RGB values are the pixel you clicked, not a nearby average, unless the tool says it samples an area. Screen colour profiles can make the same pixel look different on another monitor.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

Compare the download with the original at 100% zoom on the part you care about: a face, a line of text, or the edge of the crop.

## Where the Image Color Picker stops

Image Color Picker changes the copy you download. It does not edit the file still sitting in your folder until you replace it.

If your decision depends on a rule this page does not mention, a lender, a clinic, a teacher, a client, or the vendor of the file, use their rule. Keep this result as the draft you compare against that rule.

## Questions

### What does the Image Color Picker do?

It is there to pick HEX/RGB colors from any pixel of an image. The form on the [Image Color Picker](/image-tools/image-color-picker) page is the place you do that.

### How do I know the Image Color Picker result is usable?

Compare the download with the original at 100% zoom on the part you care about: a face, a line of text, or the edge of the crop.

### What should I not trust the Image Color Picker to decide?

Image Color Picker changes the copy you download. It does not edit the file still sitting in your folder until you replace it.
