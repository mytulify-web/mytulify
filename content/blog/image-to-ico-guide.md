[Image to ICO](/image-tools/image-to-ico) is the tool for one job: convert PNG/JPG images into Windows ICO icons. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the Image to ICO

Use the original image. Convert PNG/JPG images into Windows ICO icons.

Image to ICO runs in your browser. The file or the figures stay on your device.

## A worked pass with the Image to ICO

ICO can hold several sizes in one file. Windows uses the size that fits the place it draws. Start from a square PNG so the icon is not stretched.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

Compare the download with the original at 100% zoom on the part you care about: a face, a line of text, or the edge of the crop.

## Where the Image to ICO stops

Image to ICO changes the copy you download. It does not edit the file still sitting in your folder until you replace it.

If your decision depends on a rule this page does not mention, a lender, a clinic, a teacher, a client, or the vendor of the file, use their rule. Keep this result as the draft you compare against that rule.
