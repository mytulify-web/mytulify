[Password Entropy Calculator](/security-password-tools/password-entropy-calculator) is the tool for one job: calculate the bits of entropy in a password. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the Password Entropy Calculator

Type the value in the form. Do not use a real password as a test on any tool that sends data to a server.

Password Entropy Calculator runs in your browser. The file or the figures stay on your device.

## A worked pass with the Password Entropy Calculator

Entropy in bits is the size of the random space if the password was chosen at random. A phrase you made up is not that random. The number assumes the method the form describes.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

For a hash, change one character of the input. The digest should change completely. For a generator, generate twice and expect two different outputs.
