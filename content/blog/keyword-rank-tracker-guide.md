## What to bring to the Keyword Rank Tracker

Bring the URL, the HTML, or the keyword list the form asks for.

Keyword Rank Tracker runs in your browser. The file or the figures stay on your device.

## A worked pass with the Keyword Rank Tracker

Log keyword rankings over time in your browser and export CSV reports — no API key required. Use a real URL or a real draft. A made-up example only describes the example.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

Open the real page source or Search Console and confirm the change landed. A result on this page is not a ranking.

## Where the Keyword Rank Tracker stops

Keyword Rank Tracker does not control a search engine. It prepares or checks the input you gave it.
