[curl Command Builder](/devops-tools/curl-command-builder) is the tool for one job: build a curl command from a form and export the equivalent Python requests and JS fetch code. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the curl Command Builder

Paste a real snippet, not a description of the snippet, unless the tool asks you to describe one.

curl Command Builder runs in your browser. The file or the figures stay on your device.

## A worked pass with the curl Command Builder

Build a curl command from a form and export the equivalent Python requests and JS fetch code. Feed it a small valid sample and a sample you know is broken. The valid one should succeed and the broken one should point at the problem.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

Diff the output against the input for a formatter. For a generator, run the result in the real tool that will consume it.

## Where the curl Command Builder stops

curl Command Builder does not see your repository, your server, or the version of the library on your machine.

If your decision depends on a rule this page does not mention, a lender, a clinic, a teacher, a client, or the vendor of the file, use their rule. Keep this result as the draft you compare against that rule.

## Questions

### What does the curl Command Builder do?

It is there to build a curl command from a form and export the equivalent Python requests and JS fetch code. The form on the [curl Command Builder](/devops-tools/curl-command-builder) page is the place you do that.

### How do I know the curl Command Builder result is usable?

Diff the output against the input for a formatter. For a generator, run the result in the real tool that will consume it.

### What should I not trust the curl Command Builder to decide?

curl Command Builder does not see your repository, your server, or the version of the library on your machine.
