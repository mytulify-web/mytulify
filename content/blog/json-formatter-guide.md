[JSON Formatter](/developer-tools/json-formatter) is the tool for one job: beautify, validate and minify JSON with syntax highlighting. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the JSON Formatter

Paste a real snippet, not a description of the snippet, unless the tool asks you to describe one.

JSON Formatter runs in your browser. The file or the figures stay on your device.

## A worked pass with the JSON Formatter

Valid JSON uses double quotes and no trailing comma. The formatter only reprints it. A red error is a syntax problem, and the position is the place to look.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

Diff the output against the input for a formatter. For a generator, run the result in the real tool that will consume it.

## Where the JSON Formatter stops

JSON Formatter does not see your repository, your server, or the version of the library on your machine.

If your decision depends on a rule this page does not mention, a lender, a clinic, a teacher, a client, or the vendor of the file, use their rule. Keep this result as the draft you compare against that rule.

## Questions

### What does the JSON Formatter do?

It is there to beautify, validate and minify JSON with syntax highlighting. The form on the [JSON Formatter](/developer-tools/json-formatter) page is the place you do that.

### How do I know the JSON Formatter result is usable?

Diff the output against the input for a formatter. For a generator, run the result in the real tool that will consume it.

### What should I not trust the JSON Formatter to decide?

JSON Formatter does not see your repository, your server, or the version of the library on your machine.
