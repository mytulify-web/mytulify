[AI Error Diagnoser](/ai-tools/error-diagnoser) is the tool for one job: paste an error or stack trace and get the root cause plus the exact code fix as a diff. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the AI Error Diagnoser

Bring the real source: the code, the job post, the diff, or the file.

AI Error Diagnoser sends the input to a server so the work can run. Do not include passwords or account numbers. The free plan has a daily limit.

## A worked pass with the AI Error Diagnoser

Paste the stack trace and the lines around it. The suggested diff is a starting patch. Apply it only if you understand the line it changes.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

Check names, numbers, and any line you would ship. Change one instruction and see whether the draft follows it.

## Where the AI Error Diagnoser stops

This tool sends the input to a server so a model can run. Do not paste passwords, keys, or a client's secrets. The free plan has a daily limit.

If your decision depends on a rule this page does not mention, a lender, a clinic, a teacher, a client, or the vendor of the file, use their rule. Keep this result as the draft you compare against that rule.
