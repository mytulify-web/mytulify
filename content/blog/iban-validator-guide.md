[IBAN Validator](/converters-generators/iban-validator) is the tool for one job: validate IBAN numbers for Pakistan, EU, UK and 80+ countries with mod-97 checksum. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the IBAN Validator

Paste a real snippet, not a description of the snippet, unless the tool asks you to describe one.

IBAN Validator runs in your browser. The file or the figures stay on your device.

## A worked pass with the IBAN Validator

The IBAN check is the mod-97 remainder. A valid checksum is not proof the account exists. It is proof the characters are internally consistent for that country's length.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

Diff the output against the input for a formatter. For a generator, run the result in the real tool that will consume it.

## Where the IBAN Validator stops

IBAN Validator does not see your repository, your server, or the version of the library on your machine.

If your decision depends on a rule this page does not mention, a lender, a clinic, a teacher, a client, or the vendor of the file, use their rule. Keep this result as the draft you compare against that rule.
