[Nginx Config Generator](/devops-tools/nginx-config-generator) is the tool for one job: generate Nginx configs for reverse proxy, SSL termination, static sites and load balancing. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the Nginx Config Generator

Paste a real snippet, not a description of the snippet, unless the tool asks you to describe one.

Nginx Config Generator runs in your browser. The file or the figures stay on your device.

## A worked pass with the Nginx Config Generator

Generate Nginx configs for reverse proxy, SSL termination, static sites and load balancing. Feed it a small valid sample and a sample you know is broken. The valid one should succeed and the broken one should point at the problem.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

Diff the output against the input for a formatter. For a generator, run the result in the real tool that will consume it.

## Where the Nginx Config Generator stops

Nginx Config Generator does not see your repository, your server, or the version of the library on your machine.

If your decision depends on a rule this page does not mention, a lender, a clinic, a teacher, a client, or the vendor of the file, use their rule. Keep this result as the draft you compare against that rule.

It is there to generate Nginx configs for reverse proxy, SSL termination, static sites and load balancing. The form on the [Nginx Config Generator](/devops-tools/nginx-config-generator) page is the place you do that.
