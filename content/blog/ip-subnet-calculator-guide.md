[IP Subnet Calculator](/devops-tools/ip-subnet-calculator) is the tool for one job: calculate network, broadcast, host range and mask from a CIDR block, with a visual bit breakdown. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the IP Subnet Calculator

Paste a real snippet, not a description of the snippet, unless the tool asks you to describe one.

IP Subnet Calculator runs in your browser. The file or the figures stay on your device.

## A worked pass with the IP Subnet Calculator

A CIDR such as 192.168.1.10/24 covers 192.168.1.0 through 192.168.1.255, with the first and last addresses reserved as network and broadcast. Usable hosts are the ones in between.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

Diff the output against the input for a formatter. For a generator, run the result in the real tool that will consume it.

## Where the IP Subnet Calculator stops

IP Subnet Calculator does not see your repository, your server, or the version of the library on your machine.

If your decision depends on a rule this page does not mention, a lender, a clinic, a teacher, a client, or the vendor of the file, use their rule. Keep this result as the draft you compare against that rule.
