[Passphrase Generator](/security-password-tools/passphrase-generator) is the tool for one job: build memorable Diceware-style word passphrases. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the Passphrase Generator

Type the value in the form. Do not use a real password as a test on any tool that sends data to a server.

Passphrase Generator runs in your browser. The file or the figures stay on your device.

## A worked pass with the Passphrase Generator

Build memorable Diceware-style word passphrases. Treat the output as a secret if it is a password, a key, or a token. Copy it to a manager and clear the box.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

For a hash, change one character of the input. The digest should change completely. For a generator, generate twice and expect two different outputs.

## Where the Passphrase Generator stops

Passphrase Generator performs the operation on this page. It does not audit an account or a server.

If your decision depends on a rule this page does not mention, a lender, a clinic, a teacher, a client, or the vendor of the file, use their rule. Keep this result as the draft you compare against that rule.
