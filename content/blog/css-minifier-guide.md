[CSS Minifier](/developer-tools/css-minifier) is the tool for one job: compress CSS by stripping whitespace and comments. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the CSS Minifier

Paste a real snippet, not a description of the snippet, unless the tool asks you to describe one.

CSS Minifier runs in your browser. The file or the figures stay on your device.

## A worked pass with the CSS Minifier

Compress CSS by stripping whitespace and comments. Feed it a small valid sample and a sample you know is broken. The valid one should succeed and the broken one should point at the problem.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

Diff the output against the input for a formatter. For a generator, run the result in the real tool that will consume it.

## Where the CSS Minifier stops

CSS Minifier does not see your repository, your server, or the version of the library on your machine.

If your decision depends on a rule this page does not mention, a lender, a clinic, a teacher, a client, or the vendor of the file, use their rule. Keep this result as the draft you compare against that rule.

## Questions

### What does the CSS Minifier do?

It is there to compress CSS by stripping whitespace and comments. The form on the [CSS Minifier](/developer-tools/css-minifier) page is the place you do that.

### How do I know the CSS Minifier result is usable?

Diff the output against the input for a formatter. For a generator, run the result in the real tool that will consume it.

### What should I not trust the CSS Minifier to decide?

CSS Minifier does not see your repository, your server, or the version of the library on your machine.
