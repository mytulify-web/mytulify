[Gradient Generator](/color-tools/gradient-generator) is the tool for one job: build CSS linear and radial gradients visually. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the Gradient Generator

Have the colour as a HEX, an RGB, or the two colours the form names. Build CSS linear and radial gradients visually.

Gradient Generator runs in your browser. The file or the figures stay on your device.

## A worked pass with the Gradient Generator

A CSS linear gradient needs an angle and at least two colour stops. The code you copy should contain both colours. A radial gradient starts from a centre instead of an edge.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

Paste the result back into the reverse converter when one exists. You should land near the colour you started with.

## Where the Gradient Generator stops

Gradient Generator does the colour math on the values you type. It does not see the rest of your page.

If your decision depends on a rule this page does not mention, a lender, a clinic, a teacher, a client, or the vendor of the file, use their rule. Keep this result as the draft you compare against that rule.

It is there to build CSS linear and radial gradients visually. The form on the [Gradient Generator](/color-tools/gradient-generator) page is the place you do that.
