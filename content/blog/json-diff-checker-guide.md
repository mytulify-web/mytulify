[JSON Diff Checker](/developer-tools/json-diff-checker) is the tool for one job: compare two JSON documents with path-level added, removed, and changed highlights. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the JSON Diff Checker

Paste a real snippet, not a description of the snippet, unless the tool asks you to describe one.

JSON Diff Checker runs in your browser. The file or the figures stay on your device.

## A worked pass with the JSON Diff Checker

A changed path is a key whose value differs. An added path is only on the right. Order of keys in an object does not matter. Order in an array does.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

Diff the output against the input for a formatter. For a generator, run the result in the real tool that will consume it.

## Where the JSON Diff Checker stops

JSON Diff Checker does not see your repository, your server, or the version of the library on your machine.

If your decision depends on a rule this page does not mention, a lender, a clinic, a teacher, a client, or the vendor of the file, use their rule. Keep this result as the draft you compare against that rule.
