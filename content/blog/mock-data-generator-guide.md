[Mock Data Generator](/developer-tools/mock-data-generator) is the tool for one job: generate fake users or products as JSON or CSV for API testing and demos. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the Mock Data Generator

Paste a real snippet, not a description of the snippet, unless the tool asks you to describe one.

Mock Data Generator runs in your browser. The file or the figures stay on your device.

## A worked pass with the Mock Data Generator

Generate fake users or products as JSON or CSV for API testing and demos. Feed it a small valid sample and a sample you know is broken. The valid one should succeed and the broken one should point at the problem.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

Diff the output against the input for a formatter. For a generator, run the result in the real tool that will consume it.

## Where the Mock Data Generator stops

Mock Data Generator does not see your repository, your server, or the version of the library on your machine.

If your decision depends on a rule this page does not mention, a lender, a clinic, a teacher, a client, or the vendor of the file, use their rule. Keep this result as the draft you compare against that rule.

## Questions

### What does the Mock Data Generator do?

It is there to generate fake users or products as JSON or CSV for API testing and demos. The form on the [Mock Data Generator](/developer-tools/mock-data-generator) page is the place you do that.

### How do I know the Mock Data Generator result is usable?

Diff the output against the input for a formatter. For a generator, run the result in the real tool that will consume it.

### What should I not trust the Mock Data Generator to decide?

Mock Data Generator does not see your repository, your server, or the version of the library on your machine.
