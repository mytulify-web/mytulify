[Extract Text from PDF](/pdf-tools/extract-text-from-pdf) is the tool for one job: copy all selectable text out of a PDF as plain text. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the Extract Text from PDF

Use the PDF you mean to change, and read the page numbers the viewer shows. Copy all selectable text out of a PDF as plain text.

Extract Text from PDF runs in your browser. The file or the figures stay on your device.

## A worked pass with the Extract Text from PDF

Only text that is really text comes out. A scan is a picture and yields little or nothing. If the result is empty, the PDF needs OCR, which this page is not doing.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

Open the download and check page count, order, and one page you care about. If text used to be selectable, try to select it again.

## Where the Extract Text from PDF stops

Extract Text from PDF writes a new file. The original stays where it was until you delete it. A scan remains a picture unless this page says it reads text.

If your decision depends on a rule this page does not mention, a lender, a clinic, a teacher, a client, or the vendor of the file, use their rule. Keep this result as the draft you compare against that rule.
