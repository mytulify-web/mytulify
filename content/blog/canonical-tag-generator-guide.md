[Canonical Tag Generator](/seo-web-tools/canonical-tag-generator) is the tool for one job: create rel=canonical link tags to prevent duplicate content. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the Canonical Tag Generator

Bring the URL, the HTML, or the keyword list the form asks for.

Canonical Tag Generator runs in your browser. The file or the figures stay on your device.

## A worked pass with the Canonical Tag Generator

The canonical URL is the one you want indexed when several URLs show the same page. It should be absolute, and it should be a page that returns the same content.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

Open the real page source or Search Console and confirm the change landed. A result on this page is not a ranking.

## Where the Canonical Tag Generator stops

Canonical Tag Generator does not control a search engine. It prepares or checks the input you gave it.

If your decision depends on a rule this page does not mention, a lender, a clinic, a teacher, a client, or the vendor of the file, use their rule. Keep this result as the draft you compare against that rule.
