[Box Shadow Generator](/color-tools/box-shadow-generator) is the tool for one job: build and preview CSS box-shadow code. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the Box Shadow Generator

Have the colour as a HEX, an RGB, or the two colours the form names. Build and preview CSS box-shadow code.

Box Shadow Generator runs in your browser. The file or the figures stay on your device.

## A worked pass with the Box Shadow Generator

The CSS is offset-x, offset-y, blur, spread, and colour. A larger blur is softer. Copy the declaration into a class and confirm the preview matches.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

Paste the result back into the reverse converter when one exists. You should land near the colour you started with.

## Where the Box Shadow Generator stops

Box Shadow Generator does the colour math on the values you type. It does not see the rest of your page.

If your decision depends on a rule this page does not mention, a lender, a clinic, a teacher, a client, or the vendor of the file, use their rule. Keep this result as the draft you compare against that rule.
