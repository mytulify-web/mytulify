[PWA Manifest Generator](/developer-tools/pwa-manifest-generator) is the tool for one job: build manifest.json and HTML tags to turn your site into an installable Progressive Web App. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the PWA Manifest Generator

Paste a real snippet, not a description of the snippet, unless the tool asks you to describe one.

PWA Manifest Generator runs in your browser. The file or the figures stay on your device.

## A worked pass with the PWA Manifest Generator

Build manifest.json and HTML tags to turn your site into an installable Progressive Web App. Feed it a small valid sample and a sample you know is broken. The valid one should succeed and the broken one should point at the problem.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

Diff the output against the input for a formatter. For a generator, run the result in the real tool that will consume it.

## Where the PWA Manifest Generator stops

PWA Manifest Generator does not see your repository, your server, or the version of the library on your machine.

If your decision depends on a rule this page does not mention, a lender, a clinic, a teacher, a client, or the vendor of the file, use their rule. Keep this result as the draft you compare against that rule.

## Questions

### What does the PWA Manifest Generator do?

It is there to build manifest.json and HTML tags to turn your site into an installable Progressive Web App. The form on the [PWA Manifest Generator](/developer-tools/pwa-manifest-generator) page is the place you do that.

### How do I know the PWA Manifest Generator result is usable?

Diff the output against the input for a formatter. For a generator, run the result in the real tool that will consume it.

### What should I not trust the PWA Manifest Generator to decide?

PWA Manifest Generator does not see your repository, your server, or the version of the library on your machine.
