[Add Page Numbers to PDF](/pdf-tools/add-page-numbers-to-pdf) is the tool for one job: insert customizable page numbers into a PDF. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the Add Page Numbers to PDF

Use the PDF you mean to change, and read the page numbers the viewer shows. Insert customizable page numbers into a PDF.

Add Page Numbers to PDF runs in your browser. The file or the figures stay on your device.

## A worked pass with the Add Page Numbers to PDF

The number is drawn onto the page. It can collide with a number already printed in the document. Pick a corner that is empty.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

Open the download and check page count, order, and one page you care about. If text used to be selectable, try to select it again.

## Where the Add Page Numbers to PDF stops

Add Page Numbers to PDF writes a new file. The original stays where it was until you delete it. A scan remains a picture unless this page says it reads text.
