[JavaScript Minifier](/developer-tools/javascript-minifier) is the tool for one job: minify JavaScript source to reduce file size. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the JavaScript Minifier

Paste a real snippet, not a description of the snippet, unless the tool asks you to describe one.

JavaScript Minifier runs in your browser. The file or the figures stay on your device.

## A worked pass with the JavaScript Minifier

Minify JavaScript source to reduce file size. Feed it a small valid sample and a sample you know is broken. The valid one should succeed and the broken one should point at the problem.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

Diff the output against the input for a formatter. For a generator, run the result in the real tool that will consume it.

## Where the JavaScript Minifier stops

JavaScript Minifier does not see your repository, your server, or the version of the library on your machine.

If your decision depends on a rule this page does not mention, a lender, a clinic, a teacher, a client, or the vendor of the file, use their rule. Keep this result as the draft you compare against that rule.

## Questions

### What does the JavaScript Minifier do?

It is there to minify JavaScript source to reduce file size. The form on the [JavaScript Minifier](/developer-tools/javascript-minifier) page is the place you do that.

### How do I know the JavaScript Minifier result is usable?

Diff the output against the input for a formatter. For a generator, run the result in the real tool that will consume it.

### What should I not trust the JavaScript Minifier to decide?

JavaScript Minifier does not see your repository, your server, or the version of the library on your machine.
