[Bcrypt Generator](/security-password-tools/bcrypt-generator) is the tool for one job: hash passwords with bcrypt and verify them, with adjustable rounds. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the Bcrypt Generator

Type the value in the form. Do not use a real password as a test on any tool that sends data to a server.

Bcrypt Generator runs in your browser. The file or the figures stay on your device.

## A worked pass with the Bcrypt Generator

Bcrypt has a cost factor, the rounds. Higher rounds are slower and harder to brute force. The hash includes a salt. Verifying should succeed only with the same password.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

For a hash, change one character of the input. The digest should change completely. For a generator, generate twice and expect two different outputs.

## Where the Bcrypt Generator stops

Bcrypt Generator performs the operation on this page. It does not audit an account or a server.
