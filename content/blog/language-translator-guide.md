[Language Translator](/text-tools/language-translator) is the tool for one job: translate text or CSV/Excel into one or many languages — each target gets its own column named after that language. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the Language Translator

Paste the text you want changed. The box is the whole input.

Language Translator sends the input to a server so the work can run. Do not include passwords or account numbers. The free plan has a daily limit.

## A worked pass with the Language Translator

Each target language is its own column when you translate a sheet. The text is sent to a translation service. Do not paste passwords. Read a sentence you know before you trust a column of product names.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

For a transform, run it and spot one line. For a count, count one sentence yourself and compare.

## Where the Language Translator stops

Language Translator sees the text in the box. It does not open a file on your computer until you paste or upload.

If your decision depends on a rule this page does not mention, a lender, a clinic, a teacher, a client, or the vendor of the file, use their rule. Keep this result as the draft you compare against that rule.

## Questions

### What does the Language Translator do?

It is there to translate text or CSV/Excel into one or many languages — each target gets its own column named after that language. The form on the [Language Translator](/text-tools/language-translator) page is the place you do that.

### How do I know the Language Translator result is usable?

For a transform, run it and spot one line. For a count, count one sentence yourself and compare.

### What should I not trust the Language Translator to decide?

Language Translator sees the text in the box. It does not open a file on your computer until you paste or upload.
