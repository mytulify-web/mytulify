[Delete PDF Pages](/pdf-tools/delete-pdf-pages) is the tool for one job: remove selected pages from a PDF document. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the Delete PDF Pages

Use the PDF you mean to change, and read the page numbers the viewer shows. Remove selected pages from a PDF document.

Delete PDF Pages runs in your browser. The file or the figures stay on your device.

## A worked pass with the Delete PDF Pages

Deleted pages are gone from the download. The page count should fall by the number you removed. The original file is unchanged.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

Open the download and check page count, order, and one page you care about. If text used to be selectable, try to select it again.

## Where the Delete PDF Pages stops

Delete PDF Pages writes a new file. The original stays where it was until you delete it. A scan remains a picture unless this page says it reads text.
