[Argon2 Hash Generator](/security-password-tools/argon2-hash-generator) is the tool for one job: hash passwords with Argon2id, with tunable parameters. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the Argon2 Hash Generator

Type the value in the form. Do not use a real password as a test on any tool that sends data to a server.

Argon2 Hash Generator runs in your browser. The file or the figures stay on your device.

## A worked pass with the Argon2 Hash Generator

Argon2id is a password hash with memory, time, and parallelism settings. The hash string includes those settings. Verification uses them. Do not invent a shorter hash and call it Argon2.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

For a hash, change one character of the input. The digest should change completely. For a generator, generate twice and expect two different outputs.
