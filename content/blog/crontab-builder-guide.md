[Crontab Builder](/devops-tools/crontab-builder) is the tool for one job: build a cron expression and validate it against a real parser, with the next 5 run times previewed. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the Crontab Builder

Paste a real snippet, not a description of the snippet, unless the tool asks you to describe one.

Crontab Builder runs in your browser. The file or the figures stay on your device.

## A worked pass with the Crontab Builder

Build a cron expression and validate it against a real parser, with the next 5 run times previewed. Feed it a small valid sample and a sample you know is broken. The valid one should succeed and the broken one should point at the problem.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

Diff the output against the input for a formatter. For a generator, run the result in the real tool that will consume it.

## Where the Crontab Builder stops

Crontab Builder does not see your repository, your server, or the version of the library on your machine.

If your decision depends on a rule this page does not mention, a lender, a clinic, a teacher, a client, or the vendor of the file, use their rule. Keep this result as the draft you compare against that rule.

## Questions

### What does the Crontab Builder do?

It is there to build a cron expression and validate it against a real parser, with the next 5 run times previewed. The form on the [Crontab Builder](/devops-tools/crontab-builder) page is the place you do that.

### How do I know the Crontab Builder result is usable?

Diff the output against the input for a formatter. For a generator, run the result in the real tool that will consume it.

### What should I not trust the Crontab Builder to decide?

Crontab Builder does not see your repository, your server, or the version of the library on your machine.
