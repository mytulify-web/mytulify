[Morse Code Translator](/text-tools/morse-code-translator) is the tool for one job: encode and decode between text and Morse code, with optional audio. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the Morse Code Translator

Paste the text you want changed. The box is the whole input.

Morse Code Translator runs in your browser. The file or the figures stay on your device.

## A worked pass with the Morse Code Translator

Letters are dots and dashes. Words are separated by a longer gap. A slash or a space in the output is the word gap. Play the audio if you have it and follow one word you know.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

For a transform, run it and spot one line. For a count, count one sentence yourself and compare.

## Where the Morse Code Translator stops

Morse Code Translator sees the text in the box. It does not open a file on your computer until you paste or upload.

If your decision depends on a rule this page does not mention, a lender, a clinic, a teacher, a client, or the vendor of the file, use their rule. Keep this result as the draft you compare against that rule.
