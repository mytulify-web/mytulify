[AES Text Encrypt/Decrypt](/security-password-tools/aes-encrypt-decrypt) is the tool for one job: encrypt and decrypt text with AES-GCM and a passphrase, fully client-side. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the AES Text Encrypt/Decrypt

Type the value in the form. Do not use a real password as a test on any tool that sends data to a server.

AES Text Encrypt/Decrypt runs in your browser. The file or the figures stay on your device.

## A worked pass with the AES Text Encrypt/Decrypt

AES-GCM needs the same passphrase to decrypt. A wrong passphrase fails. It does not 'almost' decrypt. The work stays in the browser on this page.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

For a hash, change one character of the input. The digest should change completely. For a generator, generate twice and expect two different outputs.

## Where the AES Text Encrypt/Decrypt stops

AES Text Encrypt/Decrypt performs the operation on this page. It does not audit an account or a server.

If your decision depends on a rule this page does not mention, a lender, a clinic, a teacher, a client, or the vendor of the file, use their rule. Keep this result as the draft you compare against that rule.
