[Color Palette Generator](/color-tools/color-palette-generator) is the tool for one job: generate harmonious color palettes instantly. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the Color Palette Generator

Have the colour as a HEX, an RGB, or the two colours the form names. Generate harmonious color palettes instantly.

Color Palette Generator runs in your browser. The file or the figures stay on your device.

## A worked pass with the Color Palette Generator

A harmonious palette is a set of hues related by a rule, not five random colours. Lock the brand colour if the tool lets you, and read the HEX of each swatch.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

Paste the result back into the reverse converter when one exists. You should land near the colour you started with.

## Where the Color Palette Generator stops

Color Palette Generator does the colour math on the values you type. It does not see the rest of your page.

If your decision depends on a rule this page does not mention, a lender, a clinic, a teacher, a client, or the vendor of the file, use their rule. Keep this result as the draft you compare against that rule.
