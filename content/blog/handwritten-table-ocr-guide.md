[Handwritten Table OCR](/handwriting-ocr/handwritten-table-ocr) is the tool for one job: turn a photo of a handwritten table or grid into Markdown, CSV, or JSON rows. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the Handwritten Table OCR

Photograph the grid so the lines are visible. Choose Markdown, CSV, or JSON for the tool that will open the table next.

Handwritten Table OCR sends the input to a server so the work can run. Do not include passwords or account numbers. The free plan has a daily limit.

## A worked pass with the Handwritten Table OCR

Use a small table, three columns by four rows, whose totals you can add by hand. If a number jumps a column, the total will not match.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

Open the CSV in a spreadsheet and check the header row. Merged cells in the photo often become repeated or empty cells.

## Where the Handwritten Table OCR stops

It does not invent rows that were outside the photo, and a stained grid line can split one cell into two.

If your decision depends on a rule this page does not mention, a lender, a clinic, a teacher, a client, or the vendor of the file, use their rule. Keep this result as the draft you compare against that rule.
