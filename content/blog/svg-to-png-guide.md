[SVG to PNG](/image-tools/svg-to-png) is the tool for one job: rasterize SVG vector files to PNG at any size. This guide covers the inputs to gather, one pass you can check, and the point where the result stops being enough.

## What to bring to the SVG to PNG

Start from the original SVG file, not a screenshot of it.

SVG to PNG runs in your browser. The file or the figures stay on your device.

## A worked pass with the SVG to PNG

SVG is vectors. PNG is pixels. Pick the pixel size you will display, because a small PNG looks soft if you stretch it later.

Do that pass with a case you already understand. Then replace it with the real case. Changing one input at a time is how you see which field actually moved the result.

## How to check the result

Open the download at the size you will use. Check transparency, text, and the file size against the original.

## Where the SVG to PNG stops

SVG to PNG converts the file. It does not recover detail the source never had.

If your decision depends on a rule this page does not mention, a lender, a clinic, a teacher, a client, or the vendor of the file, use their rule. Keep this result as the draft you compare against that rule.
